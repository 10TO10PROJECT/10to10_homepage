**카피 소스** (수치 락 — 임의 변경 금지, SSOT = `../../../docs/plans/2026-07-27-stage-bm-v1.md` §1):

- 헤드라인 예: "설명회 하루가, 학원의 한 학기를 바꿉니다" / 서브: "모객 20명 → 신규 등록 6명 → 예상 매출 720만 원. 감이 아니라 계산입니다."
- 단계형 시각화 권장 (20명 → 6명 → 720만 3단 카운터) — 표보다 흐름.
