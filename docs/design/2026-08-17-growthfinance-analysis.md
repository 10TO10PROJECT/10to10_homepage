## 2. 10to10 차용 포인트 (우선순위순)

### 즉시 차용 가능 (P0)
1. **"무료 모객 진단" 리드 마그넷** — 히어로 보조 CTA + 네비 상주 + 스크롤 중간 배너 재삽입. 현재 우리 절차 1단계가 이미 "홍보 현황 무료 진단"이므로 **오퍼를 앞으로 끌어내기만 하면 됨**. 카톡 상담보다 진입장벽 낮은 오퍼 (멘토링 때도 도출된 아이디어).
2. **원장님 혼자 vs STAGE 전담팀 — 공정 칩 비교** — POINT 02의 8분야 칩 대비를 6공정(기획·디자인·모객·쿠폰·현장·리포트)으로 번안. 멘토 제공 As-is/To-be 장표와 동일 로직이라 사업계획서 장표를 웹 컴포넌트로 재활용 가능.
3. **비용 앵커링 3컷** — "따로 맡기면 100만+ / 직접 하면 원장님 40시간 / STAGE 100만(파트너 50만)" 구조. POINT 03의 75% 절감 뱃지 문법.

### 사례 축적 후 차용 (P1)
4. **실명 고객 사례 3카드** — 파트너 1·2호 완주 후 "○○학원, 등록 N명" + 원장 한 줄 인용. 성공 사례 공개 동의 조건(50만 특별가)과 정확히 맞물림.
5. **성과 리포트 실물 공개** — SERVICE 섹션의 "문제→원인→목표→액션" 실데이터 문법으로, 우리 성과 리포트(신청→참석→상담→등록) 샘플 1장을 실물 스크린샷으로.
6. **대표 1인칭 브릿지 강화** — 현 TeamCredential에 CEO 얼굴 사진 + "대표 신현우입니다" 1인칭 인사 도입 (현재는 3인칭 이력 카드).

### 해당 없음 / 보류
- 바우처 섹션(정부지원 세그먼트): 우리 고객(학원장)에겐 해당 프로그램 없음 — 스킵
- 모기업 신뢰 상속: 이미 TrustBar(중기부·모두의창업·알파브라더스)로 반영됨
- 3티어 가격: 우리는 단일 상품+옵션 정찰제가 락 — 유지

## 3. 디자인 문법 메모 (2차 폴리시 PR용)
- 질문형 헤드는 전부 **2줄 + 볼드 키워드 하이라이트**, eyebrow는 "POINT 01" 식 넘버링 — 우리 micro-label 문법과 호환
- 페인 파트는 일러스트 3컷 시퀀스로 감정선(문제→당황→해결)을 그림 — 우리는 실사 락이므로 현장 사진 3컷 시퀀스로 번안
