# 신뢰형 템플릿 번안 (2026-10-30)

외부 스타일 레퍼런스(이벤트 서비스 랜딩)의 구조만 가져와 10to10 브랜드로 번안한 기준이다.
교육 서비스이므로 "축제" 톤은 버리고, 조용하고 밝은 캔버스 위에 실측 근거를 앞세운다.

## 가져온 것
- 흰 캔버스 + 검정 단일 주력 CTA (카카오 노랑은 기능색 예외 유지)
- 작은 라운드 + 옅은 그림자 카드: 카드 16 / 이미지 14 / 버튼 10 / 뱃지 필
- 흰 섹션과 연한 그라데이션 밴드(`band-wash`)를 번갈아 배치
- 풀블리드 사진 히어로 + 어두운 오버레이 + 떠 있는 카드(실적 카드)
- 상단 공지 띠(`TrustRibbon`) — 정부 프로그램 선발 이력
- 타이트한 헤드라인 트래킹(-0.035em), 굵기 800

## 우리 것으로 바꾼 것
- 그라데이션: 인쇄물·캐러셀과 같은 연한 민트 `#B4F3E4 → #A5EEEC → #A3E3FF`(`band-brand`), 섹션 워시 `#E9FAF5 → #FFFFFF`
- 폰트: Pretendard 유지 (외부 커스텀 폰트 미사용)
- 강조: 박스형·손글씨 대신 러프 형광펜(`.hl`, 어두운 배경은 `.hl-solid`) — `public/brand/brush-hl.svg`
- 흰 배경 위 민트 글자: 대비를 위해 `--color-mint-700 #0E8A72`

## 버린 것
- 핑크·보라 계열, 이모지 버튼, 의미색(초록/주황/빨강) 장식
- 크게 기울인 타일 — 포트폴리오 포스터만 ±1.5°로 약하게
